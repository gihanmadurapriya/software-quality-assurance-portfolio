# BUG-004 – Password Update Rejects the Correct Current Password

## Module

Profile Section

## Severity

Major

## Priority

High

## Environment

* Browser: Chrome
* OS: Windows
* Environment: QA

## Preconditions

* User has a valid SESoc account.
* User knows the correct current account password.
* User is able to access Account Security Settings.

## Steps to Reproduce

1. Open the SESoc website.
2. Log in to the application.
3. Navigate to **Profile**.
4. Select **Manage Account**.
5. Open the **Security** tab.
6. Click **Update Password**.
7. Enter a valid new password.
8. Enter the same password in the **Confirm Password** field.
9. Click **Submit**.
10. When prompted, enter the correct current account password.
11. Confirm the password update.
12. Observe the result.

## Expected Result

The system should successfully verify the current password and update the account password. A success message should be displayed.

## Actual Result

The system displays the error message **"Password is incorrect. Try again, or use another method."** even though the correct current password was entered. The password cannot be updated.
