# BUG-001 – Certificate Template Image Cannot Be Uploaded When Creating an Event

## Module

Event Section

## Severity

Major

## Priority

High

## Environment

* Browser: Chrome
* OS: Windows
* Environment: QA

## Preconditions

* User is logged in with permission to create events.
* The Create Event page is accessible.
* A valid banner image and certificate template image are available.

## Steps to Reproduce

1. Open the SESoc website.
2. Navigate to the Create Event page.
3. Enter a valid event title.
4. Enter a valid date and time.
5. Enter a valid location.
6. Enter a valid event description.
7. Upload a valid banner image.
8. Enter a valid maximum attendee count.
9. Upload a valid certificate template image.
10. Submit the form.
11. Observe the result.

## Expected Result

The certificate template image should upload successfully and the event should be created successfully.

## Actual Result

The system displays the error message **"Could not get upload URL."** The certificate template image is not uploaded and event creation cannot proceed.

## Status

Open
