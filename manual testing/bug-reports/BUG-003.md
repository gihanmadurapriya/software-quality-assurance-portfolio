# BUG-003 – Resource PDF Upload Fails With “Could Not Get Upload URL” Error

## Module

Resources Section

## Severity

Major

## Priority

High

## Environment

* Browser: Chrome
* OS: Windows
* Environment: QA

## Preconditions

* User has permission to upload resources.
* A valid PDF file is available.
* The Upload Resource page is accessible.

## Steps to Reproduce

1. Open the SESoc website.
2. Navigate to the **Upload Resource** page.
3. Enter a valid resource title.
4. Enter a valid description.
5. Select a valid PDF file using the file picker.
6. Click the **Upload/Submit** button.
7. Observe the result.

## Expected Result

The PDF file should upload successfully and appear in the Resources list for SESoc members to download.

## Actual Result

The system displays the error message **"Could not get upload URL."** The PDF file is not uploaded.

Open
