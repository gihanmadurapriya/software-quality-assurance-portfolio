# BUG-005 – Active Member Count Displays 0 Despite Existing Active Members

## Module

Dashboard Overview Section

## Severity

Major

## Priority

Medium

## Environment

* Browser: Chrome
* OS: Windows
* Environment: QA

## Preconditions

* User is logged in to the Admin Dashboard.
* Active member records exist in the system.
* The user has permission to view the Dashboard Overview and Members pages.

## Steps to Reproduce

1. Open the SESoc website.
2. Log in to the Admin Dashboard.
3. Navigate to the **Overview** page.
4. Observe the **Active Members** count.
5. Navigate to the **Members** page.
6. Verify that active member records exist.
7. Compare the member count with the **Active Members** count displayed on the Overview page.

## Expected Result

The **Active Members** count on the Dashboard Overview should accurately match the number of active members in the Members page.

## Actual Result

The Dashboard Overview displays **0 Active Members** even though active member records exist and are visible on the Members page.
