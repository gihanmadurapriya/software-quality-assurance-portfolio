# BUG-002 – Manual Ticket Verification Rejects a Valid Attendee Ticket ID

## Module

Event Section

## Severity

Major

## Priority

High

## Environment

* Browser: Chrome
* OS: Windows
* Environment: QA

## Preconditions

* User is logged in to the Admin Dashboard.
* An upcoming event exists.
* A valid attendee is registered for the selected event.
* A valid Ticket ID is available.

## Steps to Reproduce

1. Open the SESoc website.
2. Log in to the Admin Dashboard.
3. Navigate to the Events tab.
4. Open an upcoming event.
5. Click the three-dot (⋮) menu.
6. Select **Scan Ticket**.
7. Select **Manual Check**.
8. Enter the valid attendee Ticket ID.
9. Click **Verify** or **Submit**.
10. Observe the result.

## Expected Result

The system should successfully validate the valid Ticket ID and display the attendee details or mark the ticket as valid.

## Actual Result

The system displays **"Invalid ID"** even though the entered Ticket ID belongs to a valid attendee registered for the selected event.
