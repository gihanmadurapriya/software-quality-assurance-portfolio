# SESoc Website Test Scenarios

## Authentication

- Verify user can log in with valid credentials.
- Verify login fails with invalid credentials.
- Verify required fields are validated.

## Navigation

- Verify navigation links work correctly.
- Verify users can navigate to required pages.
- Verify broken links are identified.

## Forms

- Verify valid form submission.
- Verify invalid input validation.
- Verify required fields.
- Verify boundary conditions.

## Events

- Verify events are displayed correctly.
- Verify event details can be viewed.
- Verify event navigation works correctly.
