# SESoc Website Test Plan

## 1. Objective

The objective of this test plan is to verify the functionality,
usability, and reliability of the SESoc Society website.

## 2. Testing Scope

Testing covers the publicly available website features and
user-facing functionality.

## 3. Testing Types

- Functional Testing
- UI Testing
- Usability Testing
- Regression Testing
- Negative Testing
- Boundary Testing

## 4. Test Environment

Browser: Google Chrome
Operating System: Windows

## 5. Test Deliverables

- Test cases
- Test execution results
- Defect reports
- Test summary
